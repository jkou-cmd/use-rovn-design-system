# Paper-derived assets

Source: Rōvn / Doc Brand Kit, file `01M0CHJM5K1AGXGCG2NP449W97`, captured 2026-09-08 through Paper MCP.

- `white-botanical-branch.png`, `hummingbird.png`: transparent artwork exported at 2× for the fixed ToC composition. Other artwork maps to original repository images in `design/paper/assets.json`.
- `list-circle-light.png`: text node TV4-0, 24 × 18 CSS px, exported at 8×.
- `list-circle-dark.png`: text node RAU-0, matching dark variant, exported at 8×.
- `footer-dot-light.png`: text node TW2-0, 6 × 9 CSS px, exported at 8×.
- `footer-dot-dark.png`: text node PJZ-0, matching dark variant, exported at 8×.

The two symbols are absent from the Inter font's character map and otherwise use an operating-system fallback font. Capturing their original Paper appearance makes them independent of that fallback. Original color and alpha are retained; runtime uses the correct light/dark asset. Typography and other text remain text. These exports do not replace the original JSX reference files.
